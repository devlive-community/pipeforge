## 字面量

| 类型 | 写法 |
|---|---|
| 字符串 | `'abc'`；字符串中的单引号写两次：`'it''s'` |
| 整数 | `42`、`-7`，类型为 `INT32`，超出范围时为 `INT64` |
| 小数 | `3.14`，类型为 `DECIMAL(3, 2)` |
| 浮点数 | `1e6`，类型为 `FLOAT64` |
| 布尔 | `TRUE`、`FALSE` |
| NULL | `NULL` |
| 日期时间 | `DATE '2026-11-07'`、`TIME '12:30:00'`、`TIMESTAMP '2026-11-07 12:30:00.123'` |
| 时间点 | `TIMESTAMP_LTZ '2026-11-07 12:30:00+08:00'`（必须带时区偏移） |
| 二进制 | `X'6869'` |
| 数组、映射 | `ARRAY[1, 2, 3]`、`MAP['k1', 1, 'k2', 2]` |

## 标识符

- 列名直接书写，不区分大小写。包含特殊字符、与关键字冲突或需要精确匹配大小写时用反引号：`` `order-id` ``、`` `Name` ``。
- 嵌套值：`address.city`（ROW 字段）、`tags[1]`（数组元素，从 1 开始）、`attrs['color']`（映射的值）。元素或键不存在时为 NULL。
- 伪列描述当前行本身：

| 伪列 | 值 |
|---|---|
| `$table` / `$db` / `$schema` | 当前行所属的表、库、模式 |
| `$rowkind` | `'INSERT'`、`'UPDATE_BEFORE'`、`'UPDATE_AFTER'` 或 `'DELETE'` |

## 运算符

优先级从高到低：

| 优先级 | 运算符 |
|---|---|
| 1 | `.`（字段）、`[]`（元素） |
| 2 | 一元 `+`、`-` |
| 3 | `*`、`/`、`%` |
| 4 | `+`、`-`、`\|\|`（字符串拼接） |
| 5 | `=`、`<>`、`!=`、`<`、`<=`、`>`、`>=`、`IS [NOT] DISTINCT FROM` |
| 6 | `IS [NOT] NULL`、`IS [NOT] TRUE`、`IS [NOT] FALSE`、`[NOT] BETWEEN`、`[NOT] IN`、`[NOT] LIKE`、`[NOT] RLIKE` |
| 7 | `NOT` |
| 8 | `AND` |
| 9 | `OR` |

- `LIKE` 匹配整个字符串：`%` 表示任意多个字符，`_` 表示一个字符；`ESCAPE '!'` 使下一个字符按字面匹配。
- `RLIKE` 在 RE2 正则表达式匹配字符串的任意一部分时为真；需要整体匹配时用 `^` 和 `$`。
- 整数之间的 `/` 得到精确的 DECIMAL；`%` 保持整数类型。

## 条件表达式

| 表达式 | 结果 |
|---|---|
| `CASE WHEN c1 THEN r1 [WHEN …] [ELSE e] END` | 第一个条件为 TRUE 的结果，否则为 `e` 或 NULL |
| `CASE x WHEN v1 THEN r1 … END` | 等同于 `CASE WHEN x = v1 THEN r1 … END` |
| `IF(c, a, b)` | `c` 为 TRUE 时为 `a`，否则为 `b` |
| `COALESCE(a, b, …)` | 第一个不为 NULL 的参数 |
| `IFNULL(a, b)` | 等同于 `COALESCE(a, b)` |
| `NULLIF(a, b)` | `a = b` 时为 NULL，否则为 `a` |

条件表达式的各个结果会转换为它们的公共类型。

## 类型转换

```sql
CAST(value AS type)       -- 无法转换时报错
TRY_CAST(value AS type)   -- 无法转换时为 NULL
```

类型可以写成逻辑类型（`INT64`、`STRING(20)`、`DECIMAL(10, 2)`），也可以用 SQL 名称（`BIGINT`、`VARCHAR(20)`、`NUMERIC(10, 2)`）。
时间点写作 `TIMESTAMP(3) WITH LOCAL TIME ZONE` 或 `TIMESTAMP_LTZ`，数组写作 `BIGINT ARRAY`。

| 从 | 到 | 规则 |
|---|---|---|
| 字符串 | 数字、布尔 | 忽略首尾空格；布尔接受 `true/false`、`t/f`、`yes/no`、`1/0` |
| 字符串 | 日期时间 | ISO 8601：`2026-11-07`、`12:30:00`、`2026-11-07 12:30:00.123`（空格或 `T`） |
| 字符串 | `TIMESTAMP_LTZ` | 带偏移（`+08:00`、`Z`）时精确转换；不带偏移时按作业时区的本地时间 |
| 数字 | 整数 | 四舍五入，超出范围报错 |
| 数字 | `DECIMAL(p, s)` | 四舍五入到 `s` 位小数，超过 `p` 位报错 |
| 任意类型 | `STRING(n)` | 超出部分截断为 `n` 个字符 |
| `TIMESTAMP` | `DATE`、`TIME` | 保留日期或一天中的时间 |

## 类型与隐式转换

不同类型的操作数只在不丢失信息时才转换为公共类型：

| 从 | 可以隐式转为 |
|---|---|
| `INT8` → `INT16` → `INT32` → `INT64` | 更宽的整数、`DECIMAL`、`FLOAT64` |
| `DECIMAL(p, s)` | 更宽的 `DECIMAL`、`FLOAT64` |
| `FLOAT32` | `FLOAT64` |
| `DATE` | `TIMESTAMP`（当天 0 点） |
| `STRING(n)` | `STRING(m)`，m ≥ n |

字符串不会被隐式转换为数字或日期。DECIMAL 运算结果的精度和小数位按 SQL 规则计算，上限 38 位：

| 运算 | 精度 | 小数位 |
|---|---|---|
| `a + b`、`a - b` | max(p1 − s1, p2 − s2) + s + 1 | s = max(s1, s2) |
| `a * b` | p1 + p2 + 1 | s1 + s2 |
| `a / b` | p1 − s1 + s2 + s | s = max(6, s1 + p2 + 1) |
