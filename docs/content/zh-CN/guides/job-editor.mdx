作业编辑器用于在运行前编写和检查作业定义。输入时它会让服务校验 YAML，在出错的位置标出问题；作业合法后显示计划和图。
它不运行作业，也不把作业保存到服务上：定义保存在你的浏览器中，直到你导出它。

<Screenshot name="job-editor" alt="作业编辑器中一个合法的作业及其计划" />

## 打开编辑器

在导航中选择**作业编辑器**，或者打开 `/editor`。第一次打开时显示一个示例作业；之后显示你最近的草稿。**加载示例**会用示例替换当前草稿。

## 编写作业

编辑器遵循[作业 DSL](../reference/job-dsl)。补全了解作业、`env` 和节点的字段，以及每个已安装插件的选项：

| 位置 | 补全内容 |
|---|---|
| 顶层 | `version`、`name`、`env`、`source`、`transform`、`sink` 等 |
| `env` 中 | `mode`、`parallelism`、`delivery`、`timezone`、`variables`，以及 `env.source` 下 Source 声明的选项 |
| 节点中 | `id`、`type`、`plugin`、`inputs`、`parallelism`，以及该节点 `type` 的选项 |
| `type:` 之后 | 该类别已安装的组件 |
| `inputs:` 之后 | Source 和 Transform 的 id |
| 有可选值的选项之后 | 它的取值，例如 `mode:` 之后的 `batch` 和 `streaming` |

补全在输入时自动打开，也可以按 **Ctrl+Space** 打开。它适用于块写法（每行一个键）；流式写法（`{ id: src, type: fake }`）仍会校验，但不提供补全。
同一个映射中已经写过的字段不会再出现。

## 问题

停止输入约半秒后，服务会[校验](../reference/api#validatejob)作业。标题旁的状态显示**合法**或问题的数量。

<Screenshot name="job-editor-problem" alt="未安装的插件在编辑器、图和问题列表中都标注在对应节点上" />

- YAML 中的错误标注在对应的行和列，并给出原因。
- 节点的问题（例如插件未安装）标注在节点上：编辑器中、图中以红色显示，**问题**标签页中带有错误码和提示。
- 问题列表中的**第 N 行**会把光标移到那里；在图中选择节点也一样。
- 警告（例如没有任何节点使用的 `env` 默认值）同样会列出。

## 字段映射

**映射**标签页用鼠标编辑 `field-mapper` 节点：把输入列拖到输出列上、重命名、修改类型，YAML 随之更新。见[字段映射编辑器](./field-mapping)。

## 计划与文本

作业合法后，**计划**标签页以表格显示 `explain` 的内容：作业设置和变量，节点及其插件、并行度和输入，每个节点的选项及每个取值的来源，
以及每个节点输出的表。**文本**标签页以文本形式显示同一份计划。计划的内容见[计划与 explain](../concepts/plan-and-explain)。

## 图

图按数据流动的方向从左到右显示节点，并在输入时跟随定义更新，即使定义暂时不合法。图会自动缩放到可用空间内；拖动可以平移，按住
**Ctrl** 或 **Cmd** 滚动滚轮可以缩放，也可以使用右上角的按钮。编辑器和图之间的分隔条可以拖动，也可以用方向键移动。

## 导入与导出

**导入**把 `.yaml`、`.yml` 或 `.json` 文件读入编辑器；**导出**把定义下载为 `<name>.yaml`。草稿在输入时保存在浏览器中，刷新页面不会丢失，
但不会同步到其他浏览器。

## 排障

| 问题 | 处理方法 |
|---|---|
| 显示“无法校验作业” | 服务没有响应；确认服务正在运行 |
| 插件未安装（`PF-PLUG-0001`） | 把插件安装到服务的插件目录，见[服务](../operations/server) |
| 选项没有补全 | 补全需要以块写法写出节点的 `type`；选项来自已安装的插件 |
