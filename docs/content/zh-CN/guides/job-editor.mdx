作业编辑器用于在运行前编写和检查作业定义。输入时它会让服务校验 YAML，在出错的位置标出问题；作业合法后显示计划和图。
它不运行作业，也不把作业保存到服务上：定义保存在你的浏览器中，直到你导出它。

<Screenshot name="job-editor" alt="作业编辑器中一个合法的作业及其计划" />

编辑器铺满浏览器窗口，顶部显示作业名和操作。中间可切换 **拓扑** 和 **YAML**，左侧查看已安装组件和当前作业的节点，右侧显示选中节点的属性。宽屏时可以拖动两侧分隔线改变宽度。窄屏时，通过编辑区工具栏打开组件库或节点配置。内容较长时，在相应面板内部滚动。

结果区默认收起。点击结果标签或向上拖动上方分隔线即可展开和调整高度。分隔线获得键盘焦点后，可以用方向键调整。双击分隔线可恢复默认尺寸。

## 打开编辑器

在导航中选择**作业编辑器**，或者打开 `/editor`。第一次打开时显示一个示例作业；之后显示你最近的草稿。**加载示例**会用示例替换当前草稿。

## 编写作业

编辑器遵循[作业 DSL](../reference/job-dsl)。补全了解作业、`env` 和节点的字段，以及每个已安装插件的选项：

| 位置 | 补全内容 |
|---|---|
| 顶层 | `version`、`name`、`env`、`source`、`transform`、`sink` 等 |
| `env` 中 | `mode`、`parallelism`、`delivery`、`timezone`、`variables`，以及 `env.source` 下 Source 声明的选项 |
| 节点中 | `id`、`type`、`plugin`、`inputs`、`parallelism`，以及该节点 `type` 的选项 |
| `type:` 之后 | 该类别已安装的组件 |
| `inputs:` 之后 | Source 和 Transform 的 id |
| 有可选值的选项之后 | 它的取值，例如 `mode:` 之后的 `batch` 和 `streaming` |

补全在输入时自动打开，也可以按 **Ctrl+Space** 打开。它适用于块写法（每行一个键）；流式写法（`{ id: src, type: fake }`）仍会校验，但不提供补全。
同一个映射中已经写过的字段不会再出现。

## 问题

停止输入约半秒后，服务会[校验](../reference/api#validatejob)作业。标题旁的状态显示**合法**或问题的数量。

<Screenshot name="job-editor-problem" alt="未安装的插件在编辑器、图和问题列表中都标注在对应节点上" />

- YAML 中的错误标注在对应的行和列，并给出原因。
- 节点的问题（例如插件未安装）标注在节点上：编辑器中、图中以红色显示，**问题**标签页中带有错误码和提示。
- 问题列表中的**第 N 行**会把光标移到那里；在图中选择节点也一样。
- 警告（例如没有任何节点使用的 `env` 默认值）同样会列出。

## 字段映射

**映射**标签页用鼠标编辑 `field-mapper` 节点：把输入列拖到输出列上、重命名、修改类型，YAML 随之更新。见[字段映射编辑器](./field-mapping)。

## 计划与文本

作业合法后，**计划**标签页以表格显示 `explain` 的内容：作业设置和变量，节点及其插件、并行度和输入，每个节点的选项及每个取值的来源，
以及每个节点输出的表。**文本**标签页以文本形式显示同一份计划。计划的内容见[计划与 explain](../concepts/plan-and-explain)。

## 编辑选项

从节点列表、拓扑或**节点配置**菜单选择节点后，可在面板内编辑选项。点击**参数说明**可查看服务端已安装组件提供的说明、默认值、范围和候选值。
修改会写回 YAML 的对应节点，保留周围的文本和注释。

- 数字、时长和文本在按 **Enter** 或离开输入框时写入；超出范围的数字或该填数字处填了文字会被拒绝并给出提示；`${env:ROWS}`
  这样的变量在任何选项中都可以使用
- 是/否选项有**默认**、**true** 和 **false** 三个选择；枚举选项有一个以**默认**开头的菜单
- 清空输入框或选择**默认**会删除该选项，使默认值生效
- 列表和映射（例如 `fake` Source 的列）只显示，需要在定义中编辑
- 敏感选项不会明文显示

写在一行里的节点（`{ id: print, type: console }`）在第一次修改它的选项时会改写为块格式。

## 试运行与数据预览

工具栏中的**试运行**在服务端运行作业，显示将要到达 Sink 的数据，但不写入任何地方：Sink 会被替换，甚至不会被规划。
如果想查看某个节点输出的数据，打开**预览**标签页，选择一个 Source 或 Transform（在图中选择节点效果相同），然后点击**运行**。

<Screenshot name="job-editor-preview" alt="示例作业的试运行及其前几行数据" />

作业在服务端自己的进程中以并行度 1 运行，使用服务端的插件和它对源端的访问权限，直到某个表读到 100 行、源端读完或经过 30 秒。
标签页显示运行的结束方式、在多长时间内读取了多少行，以及每个表的前几行数据和列名、类型；`NULL` 表示缺失值。作业失败时，
显示错误码和消息而不是数据。修改定义后，基于旧版本作业的预览会被标记出来。两者都要求作业没有问题。服务端的限制见
[预览与试运行](../operations/server#预览与试运行)。

## 图

拓扑会随 YAML 更新。把已安装组件从**组件**列表拖到画布，或点击组件按钮用自动布局添加。拖动节点可调整当前编辑会话中的位置。从输出端口拖到输入端口会更新目标节点在 YAML 中的 `inputs`。也可以用键盘依次选中两个端口。节点有多个上游时，可以在属性栏的**上游输入**里移除单条连线。

拖动画布空白处可平移，按住 **Ctrl** 或 **Cmd** 滚动滚轮或使用缩放按钮可缩放。选中节点即可查看属性，点击**定位到 YAML**可跳到对应定义。

## 导入与导出

**导入**把 `.yaml`、`.yml` 或 `.json` 文件读入编辑器；**导出**把定义下载为 `<name>.yaml`。草稿在输入时保存在浏览器中，刷新页面不会丢失，
但不会同步到其他浏览器。

## 排障

| 问题 | 处理方法 |
|---|---|
| 显示“无法校验作业” | 服务没有响应；确认服务正在运行 |
| 插件未安装（`PF-PLUG-0001`） | 把插件安装到服务的插件目录，见[服务](../operations/server) |
| 选项没有补全 | 补全需要以块写法写出节点的 `type`；选项来自已安装的插件 |
| 试运行无法连接源端 | 服务端从它自己所在的主机读取源端，需要和 Worker 相同的网络访问权限和驱动 |
