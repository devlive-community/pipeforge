**插件**页面展示服务能运行什么：每个已安装的插件及其组件；选中一个组件后，列出它的每个选项及其类型、是否必填、默认值、范围和可选值。
[作业编辑器](./job-editor)的补全使用的也是这些信息，来自 [`GET /api/v1/components`](../reference/api#getcomponent)。

## 插件

每个插件是一张卡片，显示名称、`id@版本`、许可证、说明和提供者。连接数据源的插件还会写明数据源类型、验证过的版本以及需要的驱动。
插件如何打包和加载见[插件](../concepts/plugins)。

插件目录中无法加载的插件包列在页面底部，并附上原因，例如 `plugin.yaml` 不合法。

## 组件的选项

选择一个组件，例如 **Source fake**，它的选项就显示在列表旁边。每个选项显示：

| 字段 | 含义 |
|---|---|
| 键和类型 | 作业中使用的名称，以及类型，例如 `string`、`long`、`enum` |
| 是否必填 | **必填**；**多选一**（一组选项中必须且只能设置一个）；**条件必填**（另一个选项取某个值时必填）；**可选** |
| 默认值 | 任何地方都没有设置时使用的取值（[选项作用域](../reference/job-dsl#选项作用域)） |
| 范围和可选值 | 允许的数值范围或允许的取值 |
| 旧名称 | 仍然接受的旧键名 |
| 起始版本 | 加入该选项的插件版本 |
| 敏感 | 取值在计划、日志和 API 中显示为掩码 |

选项下方列出选项之间的规则：哪些选项互斥，以及另一个选项取某个值时还必须设置哪些选项。

选中的组件是地址的一部分（`/plugins?type=source&component=fake&plugin=fake@0.1.0`），因此可以收藏或分享。

## 排障

| 问题 | 处理方法 |
|---|---|
| “没有安装插件” | 把插件包放到服务的插件目录并重启服务，见[服务](../operations/server) |
| 插件出现在无法加载的插件包中 | 按显示的原因修正（通常是它的 `plugin.yaml`），然后重启服务 |
