字段映射编辑器把作业中的一个[字段映射](../plugins/transform/field-mapper)显示为两列：左边是到达该节点的列，右边是它输出的列，
两者之间用连线相连。你的修改以小范围编辑的方式写回作业的 YAML，注释和格式保持不变，稍后计划中就会显示新的输出 Schema。

## 打开编辑器

在[作业编辑器](./job-editor)中打开**映射**标签页，或者在图中选择一个字段映射节点。作业中有 `field-mapper` Transform 时就会出现这个标签页；
有多个时，顶部的切换按钮用于选择其中一个。

列来自作业的计划，因此作业需要至少合法过一次。作业有问题时，编辑器继续显示最近一次合法版本的列，并给出提示。

## 连接列

- 把输入列拖到输出列上：该输出列改为取这一列的值，原来的表达式或常量被替换，名称保持不变。
- 把输入列拖到**新列**上：新增一个取这一列的值的输出列。原来只是被保留的列会变成 `mapping` 中的一个条目，可以重命名和修改类型。
- 输入列旁边的删除按钮把该列加入 `drop`；同一个按钮可以恢复。
- **添加列**新增一个常量列，可以再改为表达式。

每个输出列都会标明取值来源：原样保留、**表达式**或**常量**；`from` 引用了不存在的输入列时以红色标出。

## 编辑列

选择一个输出列即可查看它的字段。按 **Enter** 或离开输入框时保存。

| 字段 | 写入 |
|---|---|
| 名称 | `to` |
| 来源：列、表达式或常量 | `from`、`expr` 或 `value` |
| 类型 | `type`；留空时沿用输入框中提示的列或表达式的类型 |
| NULL：推导、允许、非空 | 不写 `nullable`、`true` 或 `false` |
| 默认值 | `default`，替换 NULL 的取值 |
| 注释 | `comment` |

**移除该列**删除这个条目；对于保留的列，**删除该列**把它加入 `drop`。

## 类型

列转换为其他类型时，标签说明对取值的影响：

| 标签 | 含义 |
|---|---|
| 放宽 | 所有取值都能放下，例如 `INT32` 到 `INT64`、`DECIMAL(10, 2)` 到 `DECIMAL(14, 2)` |
| 可能丢失数据 | 取值可能被截断、舍入或超出范围，例如 `INT64` 到 `INT16`、`STRING` 到 `STRING(10)` |
| 运行时转换 | 作业运行时转换，可能失败，例如文本转数字；失败时按 `on-error` 处理 |

## 其他列、列名与顺序

列表上方的工具栏设置整个节点的选项：**其他列**（`others`）、**列名**（`name-case`）和**顺序**（`order`）。选择默认值时，YAML 中的该选项会被移除。
具体规则见[列映射](../reference/mapping)。

## 排障

| 问题 | 处理方法 |
|---|---|
| “映射编辑器需要作业的计划” | 修正作业的问题，让它至少合法一次；列来自计划 |
| 输出列标着“没有列 …” | 它的 `from` 引用了输入中不存在的列：把正确的输入列拖到它上面 |
| 类型看起来过时了 | 作业有问题；顶部的标签说明列来自最近一次合法的版本 |
