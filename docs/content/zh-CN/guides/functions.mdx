**函数**页面列出[表达式语言](../concepts/expressions)的每个内置函数，并提供一个试验台：不写作业就能用示例取值试验表达式。
列表与[函数参考](../reference/functions)相同，语言与 UI 一致。

## 查找函数

在搜索框中输入内容，按名称、说明或签名筛选；选择分类可以进一步缩小范围：比较与条件、数值、字符串、日期时间、类型转换。
每个函数显示它的调用形式和带类型的签名、参数为 NULL 时的返回值，以及示例和结果。每次调用结果都可能不同的函数（例如 `NOW()`）标记为**不确定**。

每个函数都有自己的地址，例如 `/functions#coalesce`，打开后直接定位到该函数。

## 试验台

1. 在编辑器中写表达式。补全提供列、函数（带签名）和关键字；输入时自动打开，也可以按 **Ctrl+Space** 打开。
2. 描述一行数据：每列有名称、[类型](../concepts/data-model)（例如 `STRING`、`INT64`、`DECIMAL(10, 2)`）和以文本表示的取值。取值为空表示 NULL。可以按需添加和删除列。
3. 可以设置时区，例如 `Asia/Shanghai`；不设置时使用服务的默认时区。
4. 点击**求值**。

结果显示表达式的类型、取值或 **NULL**，以及是否确定。示例旁的**试一试**会把示例复制到编辑器中。

试验台把表达式发送到 [`POST /api/v1/expressions/evaluate`](../reference/api#evaluateexpression)，与作业中完全一样地检查类型并求值，不保存任何内容。

## 错误

表达式有误时，结果中显示错误码、消息和提示，编辑器中出错的位置会加上下划线：

| 错误 | 含义 |
|---|---|
| `PF-PLAN-0007` | 表达式无法解析或类型检查不通过，例如函数或列不存在 |
| `PF-CONF-0007` | 某列的类型或取值不合法，例如 `INT64` 列的取值为 `abc` |
| `PF-DATA-0006` | 用这些取值求值失败，例如除以零 |
