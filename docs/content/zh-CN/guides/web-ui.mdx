Web UI 是 PipeForge 服务的浏览器前端。它展示的所有内容都来自 [REST API](../reference/api)，所以在 UI 中能看到的内容也都可以通过 API
获取，之后也可以通过命令行获取。页面随所属的功能一起加入。

<Screenshot name="overview" alt="Web UI 的概览页" />

## 打开 UI

UI 构建进服务包后，由服务直接提供：

```bash
pnpm install
pnpm --filter @pipeforge/ui build
./mvnw -B -pl pipeforge-server -am package -DskipTests
java -jar pipeforge-server/target/pipeforge-server-0.1.0-SNAPSHOT-exec.jar
```

然后打开 `http://127.0.0.1:8080`。服务只监听回环接口，见[服务](../operations/server)。

## 布局

- **顶栏**：语言菜单（地球图标）和主题菜单。
- **导航**：页面列表，位于左侧；在窄屏上移到页面上方。
- **页面**：标题和简短说明，然后是内容。每个地址都可以收藏并直接打开；未知地址会显示一个带返回入口的页面。

## 主题与语言

| 设置 | 选项 | 默认值 |
|---|---|---|
| 主题 | 浅色、深色、跟随系统 | 跟随系统：随操作系统切换，系统设置变化时也会跟着变 |
| 语言 | English、中文 | 浏览器的语言 |

两项选择都保存在浏览器中。语言同时决定服务返回的消息（例如错误消息）使用的语言。

## 概览

起始页显示 UI 连接的服务以及服务上安装的内容：

| 卡片 | 内容 |
|---|---|
| 服务 | 连接状态、PipeForge 版本、连接器 API 版本和 Java 运行时 |
| 插件 | 已安装插件的数量，以及有多少插件包无法加载 |
| 内置函数 | [表达式语言](../reference/functions)的函数数量 |
| 错误码 | 已登记的[错误码](../reference/errors)数量 |

无法加载的插件包列在卡片下方并附带原因，例如 `plugin.yaml` 不合法。

## 键盘

所有操作都可以用键盘完成。按 `Tab` 首先到达**跳到正文**，可以跳过顶栏和导航。菜单用 `Enter`、`Space` 或方向键打开，用方向键、`Home`、`End`
移动，用 `Escape` 关闭，关闭后焦点回到菜单按钮。

## 排障

| 问题 | 处理方法 |
|---|---|
| 显示“无法连接服务” | 页面已加载但 API 没有响应：确认服务正在运行，然后点击**重试** |
| 地址显示的是错误对象而不是 UI | 服务打包时没有包含 UI；按上面的步骤先构建 UI |
| 插件数量中少了某个插件 | 它可能在无法加载的插件列表中，并附带原因 |
