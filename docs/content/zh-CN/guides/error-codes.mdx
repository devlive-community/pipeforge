**错误码**页面列出每个已登记的错误码，内容与[错误码参考](../reference/errors)相同，语言与 UI 一致。
从日志、命令行或 API 的返回中看到错误码时，可以在这里查阅。

<Screenshot name="error-codes" alt="错误码页面" />

## 查找错误码

在搜索框中输入错误码、名称或消息中的文字，或者选择一个类别：`CONF`（配置）、`PLAN`（计划）、`PLUG`（插件）、`DATA`（数据）、`SYS`（系统）。每一项显示：

| 字段 | 含义 |
|---|---|
| 错误码和名称 | 例如 `PF-CONF-0001 OPTION_REQUIRED`；错误码的含义永远不变 |
| 类型 | **致命**（修正原因后重新运行）、**暂时**（自动重试）或**数据**（某一条记录有问题） |
| 消息 | 标出了参数（例如 `{option}`）的文本，出错时会填入实际取值 |
| 提示 | 如何处理 |
| 参数 | 错误携带的取值，也出现在 API 的 `params` 中 |
| 已弃用 | 该错误码不再产生，但含义保持不变 |

类型和作用范围的用法见[错误处理](../concepts/errors)。

## 链接到错误码

每个错误码都有自己的地址：`#` 后面是小写的错误码，例如 `/errors#pf-plan-0007` 打开后直接定位到该错误码。可以在运维手册和工单中使用。
