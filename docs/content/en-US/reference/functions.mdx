## All functions

The list is generated from the function catalog. Every signature is type-checked and every example
is evaluated when PipeForge is built, so the results shown are the results you get. Examples run in
the time zone Asia/Shanghai at 2026-11-07 12:30:00.25 local time, in a run that started at
08:00:00.

See [expressions](../concepts/expressions) for typing and NULL rules and
[expression syntax](./expression-syntax#function-calls) for the call forms that use keywords.

The [functions page](../guides/functions) of the Web UI shows the same list with search, and a
playground to try expressions.
